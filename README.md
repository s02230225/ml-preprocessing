# Предобработка данных и кросс-валидация

**Python · NumPy · pandas**

Реализации преобразователей признаков и инструментов кросс-валидации: MinMaxScaler, StandardScaler, one-hot кодирование, статистическое кодирование категорий и out-of-fold признаки.

```bash
python3 -m pip install -r requirements.txt
python3 -m pytest -q
```

Модули можно импортировать напрямую: `from scalers import StandardScaler`. Метод fit обучает преобразователь, transform применяет его к новым данным. Признаки с нулевым разбросом обрабатываются без деления на ноль.

`FoldCounters.fit_transform(X, y)` строит обучающие признаки out-of-fold: статистика каждой строки считается на других фолдах. `transform(X_new)` использует статистику всего обучающего набора. Неизвестные категории получают нулевые среднее и частоту; сглаженное отношение рассчитывается как `(mean+a)/(frequency+b)`.

`knn_cv_score` создаёт отдельный нормализатор для каждого фолда и обучает его только на train. Тесты проверяют границы, отсутствие пересечения train/validation, работу с константами, неизвестными категориями и индексами таблиц.
